Bank Loan Analytics Dashboard | Power BI

📊 Project Overview

This project is an interactive Bank Loan Analytics Dashboard created using Microsoft Power BI.

The main objective of this project is to analyze bank loan data and understand loan applications, funded amounts, repayments, loan status, interest rates, and borrower characteristics.

🎯 Objectives

- Analyze total loan applications
- Analyze total funded amount
- Analyze total amount received
- Understand loan application trends
- Analyze loan purposes
- Compare loan terms
- Analyze home ownership
- Analyze good and bad loans
- Analyze loan status
- Compare funded amount and repayment
- Analyze average interest rate and DTI ratio

📁 Dataset

The dataset contains information related to:

- Loan applications
- Loan amount
- Funded amount
- Total amount received
- Interest rate
- DTI ratio
- Loan purpose
- Loan term
- Home ownership
- Employment information
- Loan status
